# Завершение проверки вариантов генерации

До запуска зафиксированы 18 генераций текущей версии: Mk01/Mk05/Mk10, три seed, цели `worst_regime` и `pareto`. Это закрытие недостающих ветвей, а не изменение алгоритма. Версии nominal и deadline_f1 уже имеют отдельные внешние проверки; исторические четыре цели v1 экспортируются отдельно.

На вход поступают операции, их зависимости, допустимые станки и длительности, состав партии и число станков. Вход не содержит назначений, очередей и плановых времён. Срок равен прежнему 1,1 C0; прежние C0, станки и законы F1/F2 сохраняются. Интерфейс сам строит исходное расписание и затем вызывает неизменённый текущий генератор.

Генератор имеет общий бюджет 240 с на вызов, включая построение и CP-SAT. Незавершённая оценка кандидата записывается отдельно. Родительский предел 300 с защищает от зависшего вычисления и не обозначает срыв производственного срока. Подготовка окружения, процессы, ранние остановки, генерация и внешняя проверка сохраняются; весь расчёт выполняется в Actions в пределах общего бюджета 72 runner-часа.

После фиксации всех 18 результатов открывается новый банк: 1024 независимых сценария на закон и задачу, всего 6144 уникальных историй поломок. Эти истории общие для планов; повторное применение не увеличивает выборку. DES и DAG выполняют весь банк, исходный S1 — заранее выбранные 128 историй каждого условия. Проверяются исполнение, физический баланс, полный результат партии и совпадение R с независимым счётчиком. В основных границах сохраняется декартово семейство состояний, совместимых с известными координатами; физическое сужение относится только к E3.

Обязательные сравнения: исходный план, фактически сохранённый CP-prefix каждого вызова и ранее зафиксированный полный CP-план. Цена prefix — наблюдённая часть того же вызова; это не отдельный замер standalone. Цена полного CP историческая, поэтому парное преимущество в затратах над ним не заявляется. Дополнительный поиск полезен только при внешнем улучшении выбранной цели относительно дешёвого prefix при учёте его добавленной цены.

Для худшего режима оценивается минимум вероятностей в обоих законах. Для Pareto публикуются все выбранные до теста представители; повторного отбора по тестовой частоте нет, полнота глобального фронта не заявляется. Совместные границы для вероятностей и отдельно для зарегистрированных парных сравнений определены в `provenance/objectives_closure.json`. Счётчики биномиальные; оптимизационные оценки не подаются в Клоппера—Пирсона.

Отдельно сообщаются завершённость матрицы, допустимость, качество по внешней цели и стоимость. Равенство с более дешёвым prefix или отсутствие подтверждённого улучшения не считается успехом дополнительного поиска. E1–E5 сохраняют результаты, исходный E6 остаётся PARTIAL при 300 с; завершённые повторы при 1200 с указываются отдельно. Новые банки E1–E6 не создаются.
